# E-Commerce Sales & Customer Insights

## Project Overview
This project analyzes e-commerce sales and customer data to identify sales trends, product performance, regional sales distribution, and customer insights. Python, MySQL, and Power BI are used to clean, analyze, and visualize the data.

## Objectives
- Clean and prepare the dataset using Python.
- Analyze sales performance using SQL queries.
- Identify top-performing products and customers.
- Examine monthly sales trends and regional performance.
- Develop an interactive Power BI dashboard.

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **Database:** MySQL
- **Visualization:** Microsoft Power BI
- **Version Control:** Git and GitHub

## Project Files
- `Ecommerce_Sales_Analysis.ipynb` — Python data cleaning, analysis, and visualizations.
- `Ecommerce_Sales_Analysis.sql` — SQL queries for business analysis.
- `Cleaned_Ecommerce_Data.csv` — Cleaned dataset used for analysis and dashboard development.
- `Ecommerce_Sales_Analysis.pbix` — Power BI dashboard report.

## Key Analysis Areas
- Total sales and average sales
- Sales by region and product category
- Top 10 products by sales
- Top 10 customers by spending
- Monthly sales trends
- Shipping status distribution
- Quantity and sales relationship

## Conclusion
The project demonstrates an end-to-end data analytics workflow, from data cleaning and SQL-based analysis to interactive dashboard development, supporting data-driven business insights.
